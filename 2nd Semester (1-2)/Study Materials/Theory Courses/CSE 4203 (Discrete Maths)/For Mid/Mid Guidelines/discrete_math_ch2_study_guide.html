What is a Set?

Definition 1

A set is an unordered collection of distinct objects, called elements or members. We write a ∈ A to denote that a is an element of A, and a ∉ A that a is not.

  • Z = {…, −2, −1, 0, 1, 2, …} — Integers

Subsets and Equality

Definition 3 — Subset

A is a subset of B (written A ⊆ B) if every element of A is also in B. Formally: ∀x(x ∈ A → x ∈ B)

Proper Subset

A is a proper subset of B (written A ⊂ B) if A ⊆ B AND there exists at least one element in B that is NOT in A. So A ≠ B.

Set Equality (Definition 2)

A = B if and only if A ⊆ B AND B ⊆ A. Equivalently: ∀x(x ∈ A ↔ x ∈ B)

📌 Theorem 1 — Always True

For every set S: (i) ∅ ⊆ S and (ii) S ⊆ S. The empty set is a subset of EVERY set. This is a vacuous truth — since ∅ has no elements, there's nothing to violate the condition.

⚠ The Two Faces of "Showing Subset"

To show A ⊆ B: Take arbitrary x ∈ A and prove x ∈ B.
To show A ⊄ B: Find ONE specific x ∈ A such that x ∉ B (counterexample).

Cardinality

Definition 4 — Cardinality

If a set S has exactly n distinct elements (n is a nonneg integer), then S is finite and its cardinality is n, written |S| = n.

ExamplesCardinality Examples

|{a}| = 1   |{{a}}| = 1   |{a, {a}}| = 2   |∅| = 0

⚠ Tricky: {a, {a}} has cardinality 2 NOT 3

The elements are: a and {a}. The set {a} counts as ONE element even though it contains something inside.

Power Sets ★ Exam Favourite

Definition 6 — Power Set

The power set of S, denoted 𝒫(S), is the set of ALL subsets of S. If |S| = n, then |𝒫(S)| = 2ⁿ.

Example 14Power Set of {0, 1, 2}
Find 𝒫({0, 1, 2}).
Solution

List ALL subsets — subsets of size 0, 1, 2, and 3:

𝒫({0,1,2}) = { ∅, {0}, {1}, {2}, {0,1}, {0,2}, {1,2}, {0,1,2} } Count: 2³ = 8 elements ✓

Strategy: Always start with ∅, then all singletons, then pairs, then the full set. This guarantees you don't miss any.

Example 15Power Set of ∅ and {∅}
What is 𝒫(∅)? What is 𝒫({∅})?
Solution
𝒫(∅) = {∅} ← 2⁰ = 1 element 𝒫({∅}) = {∅, {∅}} ← 2¹ = 2 elements
⚠ Critical Confusion Point

∅ (empty set) ≠ {∅} (set containing only the empty set).
Think of it like folders: ∅ is an empty folder. {∅} is a folder that contains one empty folder inside.

Exam Type𝒫(𝒫(∅)) — Nested Power Sets★ Past Year
How many elements does 𝒫(𝒫(∅)) have? Write all elements.
Solution
  1. Start: 𝒫(∅) = {∅} — this has 1 element
  2. Now apply power set again: 𝒫({∅})
    Find all subsets of {∅}: they are ∅ and {∅} itself
  3. Result: 𝒫(𝒫(∅)) = 𝒫({∅}) = {∅, {∅}}

𝒫(𝒫(𝒫(∅))): First get 𝒫(𝒫(∅)) = {∅, {∅}} (2 elements), then 𝒫 of that has 2² = 4 elements.

Cartesian Products ★ Exam Favourite

Definition 8 — Cartesian Product

A × B = {(a, b) | a ∈ A ∧ b ∈ B} — the set of ALL ordered pairs (a, b).

★ Key Facts to Remember
  • |A × B| = |A| · |B|
  • A × B ≠ B × A (order of elements in the pair changes!)
  • If A = ∅ or B = ∅, then A × B = ∅
  • A × B = B × A only when A = B or one is empty
  • (A × B) × C ≠ A × B × C (different structure)
Example 17–18Cartesian Product Computation
Let A = {1, 2} and B = {a, b, c}. Find A × B and B × A. Show they are not equal.
Solution
A × B = {(1,a), (1,b), (1,c), (2,a), (2,b), (2,c)} ← 2 × 3 = 6 pairs B × A = {(a,1), (a,2), (b,1), (b,2), (c,1), (c,2)} ← 3 × 2 = 6 pairs

Both have 6 elements, but the ordered pairs are different — e.g., (1,a) ∈ A×B but (1,a) ∉ B×A. So A × B ≠ B × A.

Past YearThree-Set Cartesian Product★ Past Year
Let X = {2,4}, Y = {1,4}, Z = ∅. Construct X × Y × Z.
Solution
X × Y × Z = X × Y × ∅ = ∅ Reason: For any set S, S × ∅ = ∅. Since Z = ∅, the entire product is empty. Note: X × Y = {(2,1),(2,4),(4,1),(4,4)} — 4 pairs But X × Y × Z = ∅ because there are no elements in Z to form triples.

Core Definitions

Definition 1 — Function

A function f : A → B is an assignment of exactly one element of B to each element of A. We write f(a) = b if b is the unique element assigned to a.

For f(x) = x²: Codomain is Z (all integers), but Range is {0, 1, 4, 9, 16, …}. Range is always a SUBSET of codomain. They are equal only when f is ONTO (surjective).

Past YearIs f(x) = (x+2)/(2x−1) a Bijection from ℝ to ℝ?★ Past Year
Determine whether f(x) = (x+2)/(2x−1) is a bijection from ℝ to ℝ. If not, state necessary conditions for it to be a bijection.
Analysis — Step by Step
  1. Check domain: f is UNDEFINED at x = 1/2 (denominator = 0). So f is NOT a function from all of ℝ to ℝ. Cannot be a bijection on ℝ.
  2. Check injectivity (on valid domain):
    Assume f(a) = f(b): (a+2)/(2a−1) = (b+2)/(2b−1) (a+2)(2b−1) = (b+2)(2a−1) 2ab−a+4b−2 = 2ab−b+4a−2 5b = 5a → a = b ✓ (injective on domain)
  3. Check surjectivity:
    Solve y = (x+2)/(2x−1) for x: y(2x−1) = x+2 2xy − y = x + 2 x(2y−1) = y+2 x = (y+2)/(2y−1) This is undefined when y = 1/2 → f never outputs 1/2. So f is NOT surjective onto ℝ.
  4. Conclusion: f is NEITHER injective (on full ℝ) NOR surjective on ℝ. It fails to be a bijection from ℝ to ℝ.
  5. Necessary conditions for bijection: Domain must exclude x = 1/2 (i.e., ℝ \ {1/2}), and codomain must exclude 1/2 (i.e., ℝ \ {1/2}). With f : ℝ \ {1/2} → ℝ \ {1/2}, f becomes a bijection.

Inverse Functions and Composition

Inverse Function (Definition 9)

If f : A → B is a bijection, the inverse f⁻¹ : B → A is defined by: f⁻¹(b) = a when f(a) = b. Invertible ↔ Bijection.

Composition (Definition 10)

For g : A → B and f : B → C: (f ∘ g)(a) = f(g(a)). Apply g first, then f. The range of g must be ⊆ domain of f.

⚠ Composition is NOT Commutative

f ∘ g ≠ g ∘ f in general! Order matters — always apply the inner function first.

Example 24Computing Compositions
Let f(x) = 2x+3 and g(x) = 3x+2 (Z → Z). Find f∘g and g∘f.
Solution
(f∘g)(x) = f(g(x)) = f(3x+2) = 2(3x+2)+3 = 6x+4+3 = 6x+7 (g∘f)(x) = g(f(x)) = g(2x+3) = 3(2x+3)+2 = 6x+9+2 = 6x+11 6x+7 ≠ 6x+11 → f∘g ≠ g∘f ✓

Recurrence Relations ★ Exam Favourite

Definition 4 — Recurrence Relation

A recurrence relation for {aₙ} expresses aₙ in terms of previous terms a₀, a₁, …, aₙ₋₁. A closed formula gives aₙ directly in terms of n.

Example 10Solving by Iteration (Forward Method)
Solve: aₙ = aₙ₋₁ + 3 with a₀ = 2. Find a closed formula.
Solution using Iteration
a₁ = 2 + 3 = 5
a₂ = 5 + 3 = 2 + 3·2
a₃ = 2 + 3·3
⋮
aₙ = 2 + 3n← closed formula (arithmetic progression)

Alternatively using backward substitution: start from aₙ and repeatedly replace aₙ₋₁ = aₙ₋₂ + 3, etc., until you reach a₀.

Example/Past YearSolve aₙ = naₙ₋₁ with a₀ = 1★ Past Year
Find the solution of the recurrence relation aₙ = naₙ₋₁ with initial condition a₀ = 1.
Solution via Iteration
a₁ = 1 · a₀ = 1
a₂ = 2 · a₁ = 2·1 = 2
a₃ = 3 · a₂ = 3·2 = 6
a₄ = 4 · a₃ = 4·6 = 24
aₙ = n · (n−1) · (n−2) ··· 2 · 1 = n!← closed formula

The closed formula is aₙ = n! (n factorial). This can be verified: the recurrence for factorials is exactly aₙ = n·aₙ₋₁.

Past YearCorona Virus — Tripling Recurrence★ Past Year
The number of Corona viruses triples per hour. Construct a recurrence relation. Calculate the number after 12 hours, starting with 99 viruses.
Solution
  1. Recurrence Relation: Let Cₙ = number of viruses after n hours.
    Cₙ = 3 · Cₙ₋₁, with C₀ = 99
  2. Solve by Iteration:
    C₁ = 3·C₀ = 3·99 C₂ = 3·C₁ = 3²·99 ⋮ Cₙ = 3ⁿ · 99
  3. After 12 hours:
    C₁₂ = 3¹² × 99 = 531,441 × 99 = 52,612,659 viruses
💡 This is a Geometric Sequence!

Whenever terms multiply by a constant ratio r, the closed form is aₙ = a₀ · rⁿ. This is a geometric progression.

Past YearAdvanced Recurrence: aₙ = 6aₙ₋₁ − 9aₙ₋₂★ Past Year 2024
a₁=1, a₂=3, aₙ = 6aₙ₋₁ − 9aₙ₋₂ for n≥3. Find closed form and prove by induction.
Step 1: Find Closed Form by Pattern
  1. Characteristic equation: r² = 6r − 9 → r² − 6r + 9 = 0 → (r−3)² = 0 → r = 3 (repeated root)
  2. For repeated root r=3: general solution is aₙ = (c₁ + c₂·n)·3ⁿ
  3. Use initial conditions to find c₁, c₂:
    n=1: (c₁ + c₂)·3 = 1 → c₁ + c₂ = 1/3 n=2: (c₁ + 2c₂)·9 = 3 → c₁ + 2c₂ = 1/3 Subtract: c₂ = 0, c₁ = 1/3 So aₙ = (1/3)·3ⁿ = 3ⁿ⁻¹
  4. Verify: a₁ = 3⁰ = 1 ✓, a₂ = 3¹ = 3 ✓
  5. Closed form: aₙ = 3ⁿ⁻¹
Step 2: Prove by Mathematical Induction
  1. Base cases: n=1: 3⁰=1=a₁ ✓. n=2: 3¹=3=a₂ ✓
  2. Inductive step: Assume aₖ = 3^(k−1) and a_{k−1} = 3^(k−2) for all k ≤ n.
  3. Show aₙ₊₁ = 3ⁿ:
    aₙ₊₁ = 6aₙ − 9aₙ₋₁ = 6·3^(n−1) − 9·3^(n−2) = 6·3^(n−1) − 3²·3^(n−2) = 6·3^(n−1) − 3^n = 3^(n−1)(6 − 3) = 3^(n−1) · 3 = 3ⁿ ✓

Q2a-iVenn Diagram for A ∩ (B − C)

Solution & Explanation
  1. Start with B − C: this is the region in B but NOT in C (the part of B that doesn't overlap with C).

A ∩ (B−C) = A ∩ (B ∩ C̄) = (A∩B) ∩ C̄ = (A∩B) − C Shaded region: The "A and B overlap" crescent that excludes the center (where C also overlaps)

Common Mistakes & Confusion Points

Sets — Confusing ∈ and ⊆

a ∈ A: a is an element (member) of A.
A ⊆ B: A is a subset (set relationship).

Example: {1} ∈ {{1},{2}} is TRUE (the set {1} is a member).
{1} ⊆ {1,2} is TRUE (every element of {1} is in {1,2}).
1 ∈ {1,2} TRUE but 1 ⊆ {1,2} is WRONG (1 is not a set here).

Power Set of Empty Set

𝒫(∅) = {∅} (NOT ∅!)

The empty set has exactly ONE subset: itself (∅).
So the power set contains that one subset, giving {∅}.

2⁰ = 1 → power set has 1 element ✓

Proper vs Regular Subset

A ⊆ B: A is a subset (A can equal B).
A ⊂ B: A is a PROPER subset (A ≠ B AND A ⊆ B).

Every set is a subset of itself, but NOT a proper subset of itself!
A ⊆ A is always TRUE.
A ⊂ A is always FALSE.

Function — Not a Function?

f is NOT a function if:
(1) Some input has no output.
(2) Some input maps to TWO DIFFERENT outputs.

f(x) = ±√x is NOT a function (two outputs).
f(x) = 1/x is NOT a function from ℝ→ℝ (undefined at 0).
f(x) = √x is NOT a function from Z→Z (negative inputs).

Onto vs Range = Codomain

Onto (surjective) means EVERY element of the codomain is an output.

f(x) = x² : Z → Z is NOT onto (no integer x with x²=−1).
f(x) = x² : Z → Z≥0 IS onto (every non-neg int is a square).

Same function, different codomains → different surjectivity!

f⁻¹ vs 1/f

f⁻¹(x) = INVERSE FUNCTION (reverses the mapping).
1/f(x) = RECIPROCAL (totally different thing!).

If f(x) = x+1, then f⁻¹(x) = x−1 (NOT 1/(x+1)).

f⁻¹ exists ONLY if f is a BIJECTION.

⚠ Recurrence Relations — Biggest Mistake

When solving by iteration, students often forget to verify the pattern algebraically. After guessing aₙ = 3n + 2, VERIFY: check that this formula satisfies the recurrence AND the initial conditions. In exams, you may be asked to prove by induction — have the closed formula ready first, then prove.

Countable and Uncountable Sets

Definition — Countable Set

A set S is countable if it is either finite OR has the same cardinality as Z⁺ (the positive integers). A set that is not countable is called uncountable. An infinite countable set is called countably infinite.

📌 Key Insight — Cantor's Result

The set of real numbers R is strictly larger than the set of integers Z, even though both are infinite. This is one of the most surprising results in mathematics — infinity comes in different sizes!

★ Cardinality Comparisons to Remember
  • |ℕ| = |ℤ| = |ℚ| = ℵ₀ (aleph-null) — countably infinite
  • |ℝ| = c (the cardinality of the continuum) — uncountably infinite

  • For finite sets: |A| = |B| ↔ there exists a bijection between A and B
  • If A ⊆ B then |A| ≤ |B|

Prove that a strictly increasing function from ℝ to itself is one-to-one.
Proof

Let f be strictly increasing. We want to show: f(a) = f(b) → a = b.

Suppose f(a) = f(b). We'll show a = b by ruling out a < b and a > b:

  • If a < b: Since f is strictly increasing, f(a) < f(b). But f(a) = f(b) — contradiction.
  • If a > b: Since f is strictly increasing, f(a) > f(b). But f(a) = f(b) — contradiction.

So the only possibility is a = b. Therefore f is injective. ✓

Exercise 33Composition of Injections is Injective
If f: B→C and g: A→B are both injective, show f∘g is injective.
Proof

Suppose (f∘g)(a₁) = (f∘g)(a₂). Then f(g(a₁)) = f(g(a₂)).

Since f is injective: g(a₁) = g(a₂).

Since g is injective: a₁ = a₂.

Therefore f∘g is injective. ✓

💡 Analogously for Surjections

If f and g are both surjective, then f∘g is also surjective. The proofs mirror each other in structure.

Step-by-Step: Bijection Proof Template

📋 Use This Template for Every Bijection Problem

Follow these 4 steps in order for any function f: A → B.

  1. Check if f is well-defined (total function): Are there any input values where f is undefined? If yes, f is NOT a function from all of A to B. State the excluded values.
  2. Check Injectivity: Assume f(a) = f(b). Algebraically manipulate until you reach a = b. If this works → injective. If you find a counterexample (a ≠ b but f(a) = f(b)) → not injective.
  3. Check Surjectivity: Take arbitrary y ∈ B. Solve y = f(x) for x. If x is always in A → surjective. If some y has no solution or the solution is outside A → not surjective. Find the "missing" output values.
  4. Conclude: If both 2 and 3 pass → bijection. If not → state which condition fails and what restriction on domain/codomain would fix it.

Step-by-Step: Recurrence Proof by Induction Template

  1. State the claim: "We claim that aₙ = [your formula] for all n ≥ [base case]."
  2. Base case(s): Verify the formula for n=1 (and n=2 if the recurrence involves two previous terms). Show both sides are equal.
  3. Inductive hypothesis: "Assume aₖ = [formula] for all k with 1 ≤ k ≤ n (or specifically aₙ₋₁ and aₙ₋₂)."
  4. Inductive step: Compute aₙ₊₁ using the recurrence, then substitute the inductive hypothesis, and simplify to show it equals [formula for n+1].
  5. Conclude: "By the principle of mathematical induction, aₙ = [formula] for all n ≥ 1." ∎
