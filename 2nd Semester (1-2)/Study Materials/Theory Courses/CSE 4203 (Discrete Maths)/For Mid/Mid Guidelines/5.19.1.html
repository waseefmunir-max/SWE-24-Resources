Chapter 5.1
Mathematical Induction — Core Concepts

Mathematical induction proves statements that hold for all positive integers (or from some starting point). Think of it as an infinite ladder: if you reach the first rung, and each rung guarantees the next, you can reach every rung.

🪜 Ladder Analogy

(1) We can reach the first rung. (2) Reaching any rung k guarantees reaching rung k+1. Therefore, we can reach every rung. This is the exact logic of induction.

🁢 Domino Analogy

Domino 1 falls (basis). Every falling domino k knocks down domino k+1 (inductive step). Conclusion: all dominoes fall — infinitely many cases handled at once.

⚠ Critical Distinction — Mathematical Induction is NOT Inductive Reasoning

Mathematical induction is DEDUCTIVE, not inductive. Despite the name, it is a rigorous logical proof — not pattern-guessing from examples. The textbook explicitly flags this as a common source of confusion.

What induction CANNOT do: It cannot discover or derive new formulas. You must already have the statement. Induction only verifies something you already conjectured.
📜 Principle of Mathematical Induction

To prove P(n) is true for all positive integers n, complete TWO steps:

BASIS STEP: Show P(1) [or P(b)] is true.
INDUCTIVE STEP: Show P(k) → P(k+1) is true for all k ≥ 1 [or ≥ b].
Rule of inference: (P(1) ∧ ∀k(P(k)→P(k+1))) → ∀n P(n)
🔢
5.1 — Core
Understanding Each Step
🎯 Step 1: Basis Step
  • Show P(1) is true [or P(b) if starting from b]
  • Usually the easiest step — just substitute n = 1
  • Anchors the entire chain of reasoning
  • Missing basis step = invalid proof, even with perfect inductive step
🔄 Step 2: Inductive Step
  • Assume P(k) is true for an arbitrary fixed k ≥ 1 [this is the IH]
  • Show that P(k+1) must also be true
  • You do NOT prove P(k) — you assume it as a tool
  • Mark where you use the IH clearly in your proof
  • Usually the hardest step — look for how P(k+1) relates to P(k)
⚠ The Most Common Induction Error

"In an induction proof we assume P(k) is true for ALL positive integers." — WRONG! We assume P(k) for ONE arbitrary fixed k, then prove P(k+1) from that. Assuming P(n) for all n would be circular — that is what we are trying to prove!

Why Induction is Valid — Well-Ordering Property

Induction is valid because every nonempty set of positive integers has a least element. If P(n) were false for some n, the set S = {n : P(n) is false} would be nonempty, so it has a least element m. But P(m−1) would be true (m−1 < m so m−1 ∉ S), and the inductive step gives P(m−1) → P(m), so P(m) is true — contradiction!

5.1 — Template
Universal Proof Template
📋 Follow These Steps in Every Induction Proof
1

State the Proposition

Express: "For all n ≥ b, P(n)" — identify b (usually 1 or 0). Write P(n) explicitly.

2

Write "Basis Step"

Show P(b) is true. Substitute n = b, verify LHS = RHS (or inequality holds). State: "P(b) is true."

3

Write "Inductive Step" + State the IH

Write: "Assume P(k) is true for an arbitrary fixed integer k ≥ b." Then write out explicitly what P(k) says.

4

State What You Need to Prove

Write out explicitly what P(k+1) says. This is your target destination.

5

Prove P(k+1) Using the IH

Manipulate algebraically. When you substitute the IH, write IH above the equals/inequality sign. This is usually the hardest step.

6

Write Conclusion

"By the principle of mathematical induction, P(n) is true for all integers n ≥ b."

★ Choosing the Right Basis Step
  • P(n) for all positive integers → basis is P(1)
  • P(n) for all nonnegative integers → basis is P(0)
  • 2ⁿ < n! is false for n=1,2,3 → check small values first, use P(4)
  • Proving for n ≥ b where b ≠ 1 → use P(b) as basis
  • If recurrence uses TWO previous terms (like aₙ = f(aₙ₋₁, aₙ₋₂)) → you need TWO base cases!

5.1 — Examples 1–4
Summation Formula Proofs
Example 1

Prove: 1 + 2 + 3 + … + n = n(n+1)/2

Classic — Must Know
📌 Question

Show that for all positive integers n: 1 + 2 + … + n = n(n+1)/2

B

Basis Step (n=1)

LHS = 1.   RHS = 1(1+1)/2 = 2/2 = 1.   LHS = RHS ✓

H

Inductive Hypothesis

Assume: 1 + 2 + … + k = k(k+1)/2   for some arbitrary k ≥ 1
I

Prove P(k+1): 1 + 2 + … + k + (k+1) = (k+1)(k+2)/2

Strategy: The LHS of P(k+1) = LHS of P(k) + (k+1). Add (k+1) to both sides of IH.

1 + 2 + … + k + (k+1)
= [1 + 2 + … + k] + (k+1)
IH applied: = k(k+1)/2 + (k+1)
= k(k+1)/2 + 2(k+1)/2   [common denominator]
= [k(k+1) + 2(k+1)] / 2 = (k+1)(k+2)/2 ✓

This equals (k+1)[(k+1)+1]/2 — exactly what P(k+1) requires.

✓ Conclusion

By mathematical induction, 1 + 2 + … + n = n(n+1)/2 for all positive integers n.

Example 2

Prove: 1 + 3 + 5 + … + (2n−1) = n²

Conjecture + Prove
📌 Question

Conjecture a formula for the sum of first n positive odd integers, then prove it.

C

Conjecture Phase — Check Small Values

n=1: 1 = 1²   n=2: 1+3 = 4 = 2²   n=3: 1+3+5 = 9 = 3²   n=4: 16 = 4²

Conjecture: 1 + 3 + 5 + … + (2n−1) = n². (The nth odd integer is 2n−1.)

B

Basis (n=1)

LHS = 1. RHS = 1² = 1. ✓

H

IH: 1 + 3 + … + (2k−1) = k²

I

Prove P(k+1): 1 + 3 + … + (2k−1) + (2k+1) = (k+1)²

The (k+1)th odd integer is 2(k+1)−1 = 2k+1.

LHS = [1+3+…+(2k−1)] + (2k+1)
IH applied: = k² + (2k+1) = k² + 2k + 1 = (k+1)² ✓
✓ Conclusion

1 + 3 + 5 + … + (2n−1) = n² for all positive integers n.

Example 3

Prove: 1 + 2 + 2² + … + 2ⁿ = 2ⁿ⁺¹ − 1

Basis at n=0!
⚠ Basis at n=0 not n=1

The statement says "nonnegative integers" — basis step must show P(0), not P(1).

B

Basis (n=0)

LHS = 2⁰ = 1.   RHS = 2⁰⁺¹ − 1 = 2 − 1 = 1. ✓

H

IH: 1 + 2 + 2² + … + 2ᵏ = 2ᵏ⁺¹ − 1

I

Prove P(k+1): 1 + 2 + … + 2ᵏ + 2ᵏ⁺¹ = 2ᵏ⁺² − 1

LHS = (1 + 2 + … + 2ᵏ) + 2ᵏ⁺¹
IH applied: = (2ᵏ⁺¹ − 1) + 2ᵏ⁺¹ = 2·2ᵏ⁺¹ − 1 = 2ᵏ⁺² − 1 ✓
✓ Conclusion

1 + 2 + 4 + … + 2ⁿ = 2ⁿ⁺¹ − 1 for all nonneg. integers n. (Special case of geometric sum with a=1, r=2.)

5.1 — Examples 5–7
Proving Inequalities by Induction
Key Insight for Inequality Proofs: When proving P(k+1) from P(k), you often need extra facts like "1 ≤ 2ᵏ" or "2 < k+1 for k ≥ 4" to bridge the gap. Look for these auxiliary inequalities.
Example 5

Prove: n < 2ⁿ for all positive integers n

B

Basis (n=1)

1 < 2¹ = 2. ✓

H

IH: k < 2ᵏ

I

Prove: k+1 < 2ᵏ⁺¹

k+1 < 2ᵏ + 1   [by IH, k < 2ᵏ, so k+1 < 2ᵏ+1]
≤ 2ᵏ + 2ᵏ = 2·2ᵏ = 2ᵏ⁺¹   [since 1 ≤ 2ᵏ for all k ≥ 1]
Key auxiliary fact used: 1 ≤ 2ᵏ because 2ᵏ ≥ 2 for k ≥ 1 ≥ 1. This lets us replace +1 with +2ᵏ.
✓ Conclusion

n < 2ⁿ for all positive integers n.

Example 6

Prove: 2ⁿ < n! for all integers n ≥ 4

Basis at n=4!
⚠ This is FALSE for n=1,2,3 — Basis MUST be P(4)!

n=1: 2>1. n=2: 4>2. n=3: 8>6. Only true from n=4 onward: 2⁴=16 < 24=4!. If you use P(1) as the basis here, your proof is WRONG.

B

Basis (n=4)

2⁴ = 16 < 24 = 4! ✓

H

IH: 2ᵏ < k! for some k ≥ 4

I

Prove: 2ᵏ⁺¹ < (k+1)!

2ᵏ⁺¹ = 2 · 2ᵏ
IH applied: < 2 · k!
< (k+1) · k!   [since 2 < k+1 when k ≥ 4, so k+1 ≥ 5 > 2]
= (k+1)! ✓
✓ Conclusion

2ⁿ < n! for all integers n ≥ 4.

5.1 — Examples 8–9
Proving Divisibility Results
📖 Divisibility Rules Used in Proofs

If d|a and d|b, then d|(a+b) and d|(a−b).   Also if d|a, then d|(c·a) for any integer c. Use these to show sums of divisible parts are divisible.

Example 8

Prove: 3 | (n³ − n) for all positive integers n

Slicker direct proof: n³−n = (n−1)n(n+1) = product of 3 consecutive integers. One is always divisible by 3. So 3|(n³−n) directly. Induction works but isn't the most elegant approach here.
B

Basis (n=1)

1³ − 1 = 0 = 3·0. Since 3|0, P(1) is true. ✓

H

IH: 3 | (k³ − k)

I

Prove: 3 | (k+1)³ − (k+1)

(k+1)³ − (k+1) = (k³ + 3k² + 3k + 1) − (k + 1)
= (k³ − k) + 3k² + 3k = (k³ − k) + 3(k² + k)

IH: 3|(k³−k). Also 3|3(k²+k) obviously. Sum of two multiples of 3 is divisible by 3. ✓

✓ Conclusion

n³ − n is divisible by 3 for all positive integers n.

Example 9

Prove: 57 | (7ⁿ⁺² + 8²ⁿ⁺¹) for all n ≥ 0

Hard — Exam Favourite
⚠ Hardest Induction Proof — Learn the Algebraic Trick

The key is rewriting 7ᵏ⁺³ + 8²ᵏ⁺³ so that (7ᵏ⁺² + 8²ᵏ⁺¹) appears as a factor — then apply IH. The trick: split the coefficient 64 = 7 + 57.

B

Basis (n=0)

7⁰⁺² + 8²⁽⁰⁾⁺¹ = 7² + 8¹ = 49 + 8 = 57 = 57·1. ✓

H

IH: 57 | (7ᵏ⁺² + 8²ᵏ⁺¹)

I

Prove: 57 | 7ᵏ⁺³ + 8²ᵏ⁺³

7ᵏ⁺³ + 8²ᵏ⁺³ = 7·7ᵏ⁺² + 8²·8²ᵏ⁺¹ = 7·7ᵏ⁺² + 64·8²ᵏ⁺¹
= 7·7ᵏ⁺² + (7 + 57)·8²ᵏ⁺¹   [split 64 = 7 + 57 ← the KEY trick]
= 7·7ᵏ⁺² + 7·8²ᵏ⁺¹ + 57·8²ᵏ⁺¹
= 7(7ᵏ⁺² + 8²ᵏ⁺¹) + 57·8²ᵏ⁺¹

IH: 57|(7ᵏ⁺²+8²ᵏ⁺¹), so 57|7(7ᵏ⁺²+8²ᵏ⁺¹). Also 57|57·8²ᵏ⁺¹. So 57 divides the total. ✓

★ The Algebraic Trick Pattern
  • Expand using exponent rules: 8²ᵏ⁺³ = 8²·8²ᵏ⁺¹ = 64·8²ᵏ⁺¹
  • Split the big coefficient: 64 = 7 + 57 (so that 7 groups with 7ᵏ⁺²)
  • Form (7ᵏ⁺² + 8²ᵏ⁺¹) as a factor — that's the IH expression
  • The divisor (57) should appear as the remaining coefficient naturally
✓ Conclusion

57 | (7ⁿ⁺² + 8²ⁿ⁺¹) for all nonneg. integers n.

5.1 — Examples 10–14
Sets, De Morgan & Checkerboard Tiling
Example 10

A finite set with n elements has 2ⁿ subsets

B

Basis (n=0): Empty Set

The empty set ∅ has exactly 2⁰ = 1 subset — itself. ✓

H

IH: Every k-element set has 2ᵏ subsets

I

Prove: A (k+1)-element set T has 2ᵏ⁺¹ subsets

Write T = S ∪ {a}, where a ∈ T and S = T − {a} (so |S| = k).

Every subset of T is either a subset X of S, or X ∪ {a} for some subset X of S.

IH: S has 2ᵏ subsets. For each subset X of S, we get exactly 2 subsets of T. So T has 2·2ᵏ = 2ᵏ⁺¹ subsets. ✓

✓ Conclusion

A set with n elements has 2ⁿ subsets for all n ≥ 0.

Example 14 — Checkerboard Tiling (Creative Induction)

🎮 Claim: Every 2ⁿ×2ⁿ board with one square removed can be tiled with L-shaped right triominoes

Basis (n=1): A 2×2 board with one square removed is itself an L-triomino. ✓

Inductive Step: Split the 2ᵏ⁺¹×2ᵏ⁺¹ board into four 2ᵏ×2ᵏ quadrants. The removed square is in one quadrant — tile it by IH. For the other 3, temporarily remove the corner nearest the center, apply IH to each, then cover the 3 temporary corners with ONE single triomino.

Why it works: The center triomino bridges all 4 quadrants. Each quadrant has exactly one "missing" square — either the real removed square or the temporarily removed corner.

5.1 — Error Analysis
Invalid Proofs & How to Spot Errors
⚠ Example 15 — "All Lines Meet at a Point" (False Proof)

This famous incorrect proof tries to show any n non-parallel lines all pass through a common point. Error: The inductive step fails for k = 2. When trying to go from k=2 lines to k+1=3, the "first k" and "last k" sets share only ONE line. So points p₁ and p₂ don't have to coincide. The basis step P(2) is true, but the inductive step only works for k ≥ 3 — so the step P(2)→P(3) is the broken link.

⚠ Exercise 49 — "All Horses Same Color" (Classic Invalid Proof)

False claim: All horses in any set of n horses have the same color.
Error: The inductive step fails at k=1 → k+1=2. For k=1, "first k" = {horse 1} and "last k" = {horse 2}. The sets DON'T OVERLAP, so you can't conclude they're the same color. The overlap argument only works when k ≥ 2, but the basis is k=1, leaving a gap at the critical first step.

★ How to Spot Invalid Induction Proofs
  • Explicitly check if the inductive step works for the smallest k (k = basis value) — this is where false proofs usually break
  • Watch for set overlap arguments — they can silently fail for small k
  • If something sounds too surprising to be true, be skeptical and check k = basis value extra carefully
  • Both basis AND inductive step must be correctly done — an invalid proof might have one correct and one subtly wrong

📌 Exercise 3

P(n): 1² + 2² + ⋯ + n² = n(n+1)(2n+1)/6. Prove for all positive integers n.

B

Basis (n=1)

LHS = 1² = 1.   RHS = 1·2·3/6 = 6/6 = 1. ✓

H

IH: 1² + 2² + … + k² = k(k+1)(2k+1)/6

I

Prove P(k+1): sum + (k+1)² = (k+1)(k+2)(2k+3)/6

LHS = [1² + … + k²] + (k+1)²
IH: = k(k+1)(2k+1)/6 + (k+1)²
= (k+1)[k(2k+1)/6 + (k+1)] = (k+1)[k(2k+1) + 6(k+1)] / 6
= (k+1)[2k² + k + 6k + 6] / 6 = (k+1)(2k² + 7k + 6) / 6
= (k+1)(k+2)(2k+3) / 6 ✓   [factor: 2k²+7k+6 = (k+2)(2k+3)]
✓ Conclusion

1² + 2² + … + n² = n(n+1)(2n+1)/6 for all positive integers n.

Exercise 21

Prove: 2ⁿ > n² for all integers n > 4

B

Basis (n=5)

2⁵ = 32 > 25 = 5². ✓

2ᵏ⁺¹ = 2·2ᵏ IH > 2k²

Exercise 32

Prove: 3 | (n³ + 2n) for all positive integers n

Chapter 9.1
Relations and Their Properties
📖 Definition 1 — Binary Relation

Let A and B be sets. A binary relation from A to B is a subset R ⊆ A × B. We write aRb if (a,b) ∈ R.

📖 Definition 2 — Relation ON a Set

A relation on set A is a relation from A to A — i.e., a subset of A×A. This is the most common type studied.

📊 Functions vs Relations
  • Every function f: A→B is a relation (its graph is a subset of A×B)
  • A relation where every element of A appears as a first element exactly once = a function
  • Relations allow one-to-many: "Middletown" can belong to both New Jersey AND New York
  • Relations are a generalization of functions
📈 Counting Relations
  • If |A| = n, then |A×A| = n²
  • Each of the 2^(n²) subsets of A×A is a valid relation on A
  • Example: {a,b,c} → 2^9 = 512 relations
  • {0,1} → 2^4 = 16 relations (memorize this!)

9.1 — Core
The Four Properties of Relations
🟢 Reflexive
Every element is related to itself. No element can be "skipped."
∀a ∈ A: (a,a) ∈ R
YES: ≤, =, divides on ℤ⁺
NO: <, "is parent of," ≠
💜 Symmetric
If a relates to b, then b relates to a. Direction doesn't matter.
∀a,b: (a,b)∈R → (b,a)∈R
YES: =, "same age as," "married to"
NO: divides, <, ≤
🔴 Antisymmetric
If aRb and bRa, then a must equal b. No two distinct elements relate in both directions.
∀a,b: (a,b)∈R ∧ (b,a)∈R → a=b
YES: ≤, divides, <
NO: "same age as," ≠
🟩 Transitive
If aRb and bRc, then aRc. Like a chain — if each link holds, the whole chain holds.
∀a,b,c: (a,b)∈R ∧ (b,c)∈R → (a,c)∈R
YES: ≤, divides, "ancestor of"
NO: "parent of," "next to"
⚠ Biggest Confusion — Symmetric vs Antisymmetric are NOT Opposites!
  • A relation CAN be BOTH symmetric and antisymmetric: Example: equality R = {(a,a) | a∈A}. It's symmetric (if aRa then aRa trivially) and antisymmetric (if (a,b)∈R and (b,a)∈R then a=b — holds since only diagonal pairs exist).
  • A relation can be NEITHER: R = {(1,2),(2,1),(1,3)} — not symmetric (lacks (3,1)), not antisymmetric ((1,2)&(2,1) in R but 1≠2).
  • Antisymmetric ≠ asymmetric: Antisymmetric allows (a,a) pairs. Asymmetric (a stricter condition) forbids ALL self-loops.

Counting Reflexive Relations (Example 16)

How many reflexive relations on an n-element set?

Answer: 2^(n(n−1))

Reasoning: A×A has n² pairs. The n diagonal pairs (a,a) MUST be in any reflexive relation — no choice. The remaining n²−n = n(n−1) non-diagonal pairs can freely be included or not → 2 choices each → 2^(n(n−1)) total.

n=3: 2^(3·2) = 2⁶ = 64 reflexive relations on a 3-element set

9.1 — Composition
Composition of Relations & Powers
📖 Definition 6 — Composite of Relations

Let R be a relation from A to B, and S a relation from B to C. The composite S∘R is a relation from A to C:
(a,c) ∈ S∘R  ⟺  ∃b ∈ B: (a,b) ∈ R  and  (b,c) ∈ S

⚠ Order is Critical — Right to Left!

In S∘R, apply R FIRST, then S. The notation reads right-to-left (like function composition). S∘R ≠ R∘S in general.

Example 20

Compute S∘R

📌 Question

S = {(1,0),(2,0),(3,1),(3,2),(4,1)} from {1,2,3,4} to {0,1,2}. Find S∘R.

For each (a,b)∈R, find all (b,c)∈S → pair (a,c) goes into S∘R:

(1,1)∈R + (1,0)∈S → (1,0) ∈ S∘R
(1,4)∈R + (4,1)∈S → (1,1) ∈ S∘R
(2,3)∈R + (3,1)∈S → (2,1) ∈ S∘R
(2,3)∈R + (3,2)∈S → (2,2) ∈ S∘R
(3,1)∈R + (1,0)∈S → (3,0) ∈ S∘R
(3,4)∈R + (4,1)∈S → (3,1) ∈ S∘R

{(1,0),(1,1),(2,1),(2,2),(3,0),(3,1)}

📖 Definition 7 — Powers of a Relation

R¹ = R  |  Rⁿ⁺¹ = Rⁿ ∘ R
So R² = R∘R, R³ = R²∘R, etc.

📜 Theorem 1 — Transitivity and Powers (Key Theorem!)

R on set A is transitive  ⟺  Rⁿ ⊆ R for all n = 1, 2, 3, …

Shortcut: R is transitive ⟺ R² ⊆ R. Just check if every (a,c) reachable in 2 steps is already directly in R.

Example 22

R = {(1,1),(2,1),(3,2),(4,3)} — Find R², R³, R⁴

Compute R² = R∘R: for each (a,b)∈R and (b,c)∈R, put (a,c) in R²:

From (1,1): (1,1)∈R → (1,1). From (2,1): (1,1)∈R → (2,1). From (3,2): (2,1)∈R → (3,1). From (4,3): (3,2)∈R → (4,2).
R² = {(1,1),(2,1),(3,1),(4,2)}
R³ = R²∘R: Similar computation → R³ = {(1,1),(2,1),(3,1),(4,1)}
R⁴ = R³∘R: Verify — R⁴ = {(1,1),(2,1),(3,1),(4,1)} = R³ (STABILIZED!)
Key observation: Powers of a finite relation eventually stabilize. This relation stabilizes at R³ since all "chain" information is exhausted.

Exercise 51

Find error: "symmetric + transitive → reflexive"

📌 Exercise 51 — Spot the Error

"Proof": Let a∈A. Take b with (a,b)∈R. By symmetry (b,a)∈R. By transitivity (a,b)∈R and (b,a)∈R gives (a,a)∈R. So R is reflexive.

⚠ Error Found

The "proof" assumes there EXISTS a b such that (a,b)∈R. But if a is not related to ANY element (no pairs with a as first element), the argument never starts! Counterexample: A = {1,2}, R = {(1,1),(2,2),(1,2),(2,1)} is symmetric and transitive, and reflexive. BUT take R = ∅ on A={1,2} — symmetric ✓, transitive ✓ (vacuously), but NOT reflexive since (1,1)∉R. The error is assuming ∃b: (a,b)∈R.

Solve aₙ = 2n·aₙ₋₁, a₀ = 1

📌 Question

Find the solution of aₙ = 2naₙ₋₁ where a₀ = 1.

Method: Iterate (unroll) the recurrence backward.

aₙ = 2n·aₙ₋₁ = 2n·[2(n−1)·aₙ₋₂] = 2n·2(n−1)·[2(n−2)·aₙ₋₃] = …
= (2n)·(2(n−1))·(2(n−2))·…·(2·1)·a₀
= 2ⁿ · (n·(n−1)·…·1) · 1 = 2ⁿ · n!

Verification: a₀ = 2⁰·0! = 1 ✓  |  a₁ = 2¹·1! = 2 ✓  |  a₂ = 2²·2! = 4·2 = 8. Check: 2·2·a₁ = 4·2 = 8 ✓

✓ Answer

aₙ = 2ⁿ · n! for all n ≥ 0.

Q2b — 14 marks (6+8)

a₁=1, a₂=3, aₙ=6aₙ₋₁−9aₙ₋₂ for n≥3 — Find closed form, then prove by induction

📌 Question

i. Find closed-form formula for aₙ. ii. Prove it is correct for all n ≥ 1 using mathematical induction.

Part i — Closed Form (Characteristic Equation Method)

Linear homogeneous recurrence with constant coefficients. Characteristic equation:

r² = 6r − 9  ⟹  r² − 6r + 9 = 0  ⟹  (r−3)² = 0

Repeated root r = 3. General solution for repeated root:

aₙ = (C₁ + C₂n) · 3ⁿ

Apply initial conditions a₁ = 1, a₂ = 3:

n=1: (C₁ + C₂)·3 = 1  ⟹  C₁ + C₂ = 1/3
n=2: (C₁ + 2C₂)·9 = 3  ⟹  C₁ + 2C₂ = 1/3
Subtracting: C₂ = 0. Then C₁ = 1/3.
aₙ = (1/3)·3ⁿ = 3ⁿ/3 = 3ⁿ⁻¹

Check: a₁=3⁰=1 ✓, a₂=3¹=3 ✓, a₃=6(3)−9(1)=9=3² ✓

Part ii — Proof by Mathematical Induction

⚠ Need TWO base cases — recurrence uses aₙ₋₁ AND aₙ₋₂

When a recurrence involves two previous terms, both P(1) and P(2) must be verified in the basis step.

B

Basis Step

P(1): a₁ = 3¹⁻¹ = 3⁰ = 1 ✓ (matches given a₁=1)

P(2): a₂ = 3²⁻¹ = 3¹ = 3 ✓ (matches given a₂=3)

H

Inductive Hypothesis (Strong Form)

Assume P(j) is true for all j with 1 ≤ j ≤ k (k ≥ 2):   aⱼ = 3^(j−1).

In particular: aₖ = 3^(k−1) and aₖ₋₁ = 3^(k−2).

I

Prove P(k+1): aₖ₊₁ = 3ᵏ

aₖ₊₁ = 6aₖ − 9aₖ₋₁   [by recurrence relation]
IH applied: = 6·3^(k−1) − 9·3^(k−2)
= 2·3·3^(k−1) − 3²·3^(k−2) = 2·3ᵏ − 3ᵏ = 3ᵏ ✓

Key steps: 6·3^(k−1) = 2·3·3^(k−1) = 2·3ᵏ and 9·3^(k−2) = 3²·3^(k−2) = 3ᵏ

✓ Conclusion

By mathematical induction, aₙ = 3^(n−1) for all n ≥ 1.

Q4b — 10 marks

Show n³ − n is divisible by 6 for all n ∈ ℕ₀

📌 Question

Show that n³ − n is divisible by 6 for all n ∈ ℕ₀ using an appropriate proof technique.

Method 1 — Direct Proof (Best Approach)

n³ − n = n(n²−1) = n(n−1)(n+1) = (n−1)·n·(n+1)

This is the product of THREE consecutive integers: n−1, n, n+1.

Divisible by 2: Among any 3 consecutive integers, at least one is even → 2 | (n−1)n(n+1).

Divisible by 3: Among any 3 consecutive integers, exactly one is divisible by 3 → 3 | (n−1)n(n+1).

Since gcd(2,3)=1 and both 2 and 3 divide the product, we have 6 | n³−n. ✓

Method 2 — By Mathematical Induction

B

Basis (n=0)

0³ − 0 = 0. 6|0 (since 0 = 6·0). ✓

H

IH: 6 | (k³ − k)

I

Prove: 6 | (k+1)³ − (k+1)

(k+1)³ − (k+1) = k³ + 3k² + 3k + 1 − k − 1 = (k³ − k) + 3k² + 3k
= (k³ − k) + 3k(k+1)

IH: 6|(k³−k). For 3k(k+1): k and k+1 are consecutive → one is even → k(k+1)=2m → 3k(k+1)=6m → 6|3k(k+1). Sum of two multiples of 6 → 6 divides the whole expression. ✓

✓ Conclusion

6 | (n³−n) for all n ∈ ℕ₀.

Q4c — 10 marks (2×5)

R = {(a,b) | a ≡ b (mod 7)} — all properties + partial order?

📌 Question

Determine whether R is: i. Reflexive. ii. Symmetric. iii. Antisymmetric. iv. Transitive. v. Discuss whether R qualifies as a partial order.

i

Reflexive — YES ✓

For any integer a: a − a = 0, and 7|0 (0 = 7·0). So a ≡ a (mod 7), meaning (a,a) ∈ R for all a ∈ ℤ. R is reflexive.

ii

Symmetric — YES ✓

Suppose (a,b) ∈ R. Then 7|(a−b), so a−b = 7k for some integer k. Then b−a = −7k = 7(−k), so 7|(b−a), meaning (b,a) ∈ R. R is symmetric.

iii

Antisymmetric — NO ✗

Counterexample: a=1, b=8. Then 1−8 = −7 and 7|(−7), so (1,8) ∈ R. Also 8−1 = 7 and 7|7, so (8,1) ∈ R. But 1 ≠ 8. This violates antisymmetry. R is NOT antisymmetric.

iv

Transitive — YES ✓

If (a,b)∈R and (b,c)∈R, then 7|(a−b) and 7|(b−c). So 7|((a−b)+(b−c)) = 7|(a−c), meaning (a,c)∈R. R is transitive.

v

Partial Order?

A partial order requires: Reflexive ✓ + Antisymmetric ✗ + Transitive ✓. Since R is NOT antisymmetric, R is NOT a partial order.

Since R is reflexive + symmetric + transitive, it is an equivalence relation. Its equivalence classes are [0],[1],[2],[3],[4],[5],[6] — the 7 residue classes modulo 7.
