Section 1.1

Propositional Logic

Definition
Proposition

A proposition is a declarative sentence that is either true or false, but not both. The truth value is denoted T (true) or F (false). Propositions that cannot be broken into simpler ones are called atomic propositions.

Which are propositions?
  • "Washington D.C. is the capital of USA" → ✅ Proposition (True)
  • "Toronto is the capital of Canada" → ✅ Proposition (False)
  • "1 + 1 = 2" → ✅ Proposition (True)
  • "What time is it?" → ❌ Not a proposition (question)
  • "x + 1 = 2" → ❌ Not a proposition (variable unassigned)
  • "Read this carefully." → ❌ Not a proposition (command)
⚠️
Common Confusion: What is NOT a proposition?
Questions, commands, and sentences with unassigned variables (like x+1=2) are NOT propositions. They become propositions only when variables are assigned specific values.

🔥
The Most Important (and Confusing) Truth Table Row: p→q
When p is FALSE, the implication p→q is ALWAYS TRUE regardless of q. Think of it like a promise: "If it rains, I'll bring an umbrella." If it doesn't rain, the promise is never broken — it's automatically true. The only way to break a promise (make it false) is: it DID rain (p=T) but you did NOT bring an umbrella (q=F).

Conditional Statements in Depth

Definition
p → q (Conditional)

In p → q: p is the hypothesis/antecedent/premise and q is the conclusion/consequence.
It is false only when p is true and q is false.

🔥
Confusing: "p only if q" means p → q, NOT q → p!
"p only if q" = "p can only be true IF q is true" = if p is true, q must be true = p → q.
"q unless ¬p" also means p → q: "q is true, unless ¬p is true (i.e., p is false)".
"q necessary for p": Without q, you can't have p → q must be true when p is true → p → q.
"p sufficient for q": p alone is enough to guarantee q → p → q.

Find converse, contrapositive, inverse of: "The home team wins whenever it is raining."

First rewrite: "If it is raining, then the home team wins." → p = "raining", q = "home team wins"

  • Original: p → q: "If it is raining, the home team wins."
  • Contrapositive: ¬q → ¬p: "If the home team does not win, then it is not raining." ← EQUIVALENT!
  • Converse: q → p: "If the home team wins, then it is raining." ← NOT equivalent
  • Inverse: ¬p → ¬q: "If it is not raining, the home team does not win." ← NOT equivalent

Biconditional Statements

Definition
p ↔ q (Biconditional / "p if and only if q")

True when p and q have the same truth value (both T or both F). Equivalent to (p→q) ∧ (q→p).

Ways to express p ↔ q:

  • "p if and only if q" (p iff q)
  • "p is necessary and sufficient for q"
  • "if p then q, and conversely"
  • "p exactly when q"

Operator Precedence

📌
Precedence Order (Highest to Lowest)
¬ (1) → ∧ (2) → ∨ (3) → → (4) → ↔ (5)

Example: ¬p ∧ q → r ↔ s parses as ((¬p) ∧ q) → r) ↔ s
Note: Quantifiers ∀, ∃ have higher precedence than all connectives.

Section 1.2

Applications of Propositional Logic

Translating English to Logic

The key skill: identify propositions (atomic statements), then find the logical connective. Pay special attention to "unless", "only if", "when", "provided that".

Translate: "You cannot ride the roller coaster if you are under 4 feet tall unless you are older than 16 years old."

Define: q = "You can ride", r = "You are under 4 feet tall", s = "You are older than 16"

Parse: "cannot ride if (under 4 feet AND NOT older than 16)"

(r ∧ ¬s) → ¬q

Interpretation: If you are under 4 feet tall AND not older than 16, then you cannot ride.

Determine if these specs are consistent: (1) "The diagnostic message is stored in the buffer or retransmitted." (2) "The message is NOT stored in the buffer." (3) "If stored in the buffer, it is retransmitted."

Let p = "stored in buffer", q = "retransmitted"

Specs: (1) p∨q, (2) ¬p, (3) p→q

Check consistency: Set p=F (from spec 2): spec 3 becomes F→q = T (vacuously true). Spec 1 becomes F∨q, so q must be T.

When p=F, q=T: all three specs are satisfied. ✅ Consistent!

Logic Puzzles (Knights and Knaves)

A says "B is a knight" and B says "The two of us are opposite types." What are A and B?

Let p = "A is a knight", q = "B is a knight".

Case 1: Assume A is a knight (p=T).
Then A tells truth → q=T (B is a knight).
B (knight) says "we are opposite types": (p∧¬q)∨(¬p∧q) = (T∧F)∨(F∧T) = F. Contradiction! A can't be knight.

Case 2: Assume A is a knave (p=F).
A lies → q=F (B is NOT a knight, B is a knave).
B (knave) says "we are opposite types" → this is a LIE → they are same type. F=F ✅ both knaves.

∴ Both A and B are knaves.

§1.2 Exercise Solutions

Translate: "You cannot edit a protected Wikipedia entry unless you are an administrator." (e = can edit, a = administrator)

"unless" means "if not": "you cannot edit unless admin" = "if not admin, cannot edit" = ¬a → ¬e

Equivalently (contrapositive): e → a — "If you can edit, you are an administrator."

¬a → ¬e ≡ e → a
Are these consistent? "The system is in multiuser state iff operating normally." "If operating normally, kernel is functioning." "Kernel is not functioning OR system is in interrupt mode." "If not in multiuser state, then in interrupt mode." "System is NOT in interrupt mode."

Variables: p=multiuser, q=normal, r=kernel, s=interrupt
Specs: p↔q, q→r, ¬r∨s, ¬p→s, ¬s

From ¬s: s=F. From ¬p→s=F (s=F), we need ¬p=F → p=T. From p↔q: q=T. From q→r: r=T. From ¬r∨s: ¬T∨F = F. CONTRADICTION! ✗ Inconsistent.

Propositional Equivalences

Definitions
Tautology, Contradiction, Contingency
  • Tautology: Always TRUE for every combination of truth values (e.g., p∨¬p)
  • Contradiction: Always FALSE for every combination (e.g., p∧¬p)
  • Contingency: Neither always true nor always false — depends on values
  • Logically Equivalent (p≡q): p↔q is a tautology. Same truth table column.
💡
How to prove p≡q without truth tables
Use the known equivalences in Table 6 (absorption, identity, De Morgan, etc.) and apply them step by step, citing each law you use. This method scales to large expressions. Start with one side and transform to the other.

Predicates and Quantifiers

Definition
Predicate (Propositional Function)

A predicate P(x) is a statement containing variable x that becomes a proposition when a specific value is assigned to x. P is the predicate, x is the subject variable.

Example: P(x) = "x > 3". Then P(4)=T, P(2)=F.

Quantifiers

Universal Quantifier ∀
∀xP(x) = "For all x, P(x)"
TRUE if P(x) holds for every x in domain
FALSE if there exists ANY x where P(x) is false (counterexample)
Existential Quantifier ∃
∃xP(x) = "There exists x such that P(x)"
TRUE if P(x) is true for AT LEAST ONE x
FALSE if P(x) is false for EVERY x in domain
StatementWhen TRUEWhen FALSE
∀xP(x)P(x) true for every x in domain∃ at least one x where P(x) is false
∃xP(x)∃ at least one x where P(x) is trueP(x) is false for every x in domain
🔥
Domain is Critical!
∀x(x² ≥ x) is FALSE over real numbers (fails for x=0.5: 0.25 < 0.5) but TRUE over integers (no integer between 0 and 1). Always specify the domain!

Translating English to Predicates

Let V={1,2,...,30}, A[i]=i×i-i. Write predicates for: (i) Every entry is nonneg. (ii) A[30] is largest. (iii) Every element is nonzero.

Note: A[i] = i×i - i = i(i-1), so A[1]=0, A[2]=2, A[3]=6, etc.

(i) Every entry is nonneg:

∀i (1≤i≤30 → A[i] ≥ 0)

or equivalently: ∀i∈{1,...,30} (i(i-1) ≥ 0)

(ii) A[30] is the largest value:

∀i (1≤i≤30 → A[30] ≥ A[i])

i.e., for all indices i in range, A[30] is at least as large as A[i].

(iii) Every element is nonzero:

∀i (1≤i≤30 → A[i] ≠ 0)

Note: A[1] = 1×1-1 = 0, so (iii) is actually FALSE for this array!

Express using quantifiers where domain = all integers: (i) For every integer, there is one whose sum with it is zero. (ii) Sum of squares of two integers ≥ square of their sum. (iii) Difference of two negative integers is not necessarily negative.

(i) "For every integer x, there is an integer y such that x+y=0":

∀x ∃y (x + y = 0)

(This is true — y = -x always works)

(ii) "For all integers x,y: x² + y² ≥ (x+y)²":

∀x ∀y (x² + y² ≥ (x+y)²)

Check: x²+y² ≥ x²+2xy+y² ⟺ 0 ≥ 2xy — this is NOT always true (e.g., x=y=1: 2 ≥ 4 is false). So the statement is false.

(iii) "The difference of two negative integers is not necessarily negative" — means it's NOT always negative:

∃x ∃y (x < 0 ∧ y < 0 ∧ x - y ≥ 0)

Example: x=-1, y=-2: x-y = -1-(-2) = 1 > 0. True!

Section 1.5

Nested Quantifiers

Order of Quantifiers MATTERS!

🔥
∀x∃y ≠ ∃y∀x !
This is a major exam topic. The order of different quantifiers is critical.
∀x∃y P(x,y): "For each x, there EXISTS a y (that may depend on x)"
∃y∀x P(x,y): "There EXISTS ONE y that works for ALL x simultaneously"
The second is MUCH stronger. If ∃y∀x holds, then ∀x∃y also holds, but NOT vice versa.

Key Definitions
Even, Odd, Rational, Irrational
  • n is even: ∃k∈ℤ such that n = 2k
  • n is odd: ∃k∈ℤ such that n = 2k + 1
  • r is rational: ∃p,q∈ℤ, q≠0, such that r = p/q
  • r is irrational: NOT rational

Direct Proof — Examples

Theorem: If n is an odd integer, then n² is odd. (Direct Proof)

Proof: Assume n is odd. By definition, n = 2k+1 for some integer k.

Then: n² = (2k+1)² = 4k² + 4k + 1 = 2(2k² + 2k) + 1

Since 2k²+2k is an integer, n² = 2m+1 where m = 2k²+2k. By definition, n² is odd. □

Prove that if x,y are real numbers, then max(x,y) + min(x,y) = x+y. (CSE 4203 Mid 2022-23)

Proof by Cases:

Case 1: x ≥ y.
Then max(x,y) = x and min(x,y) = y.
max(x,y) + min(x,y) = x + y = x + y. ✅

Case 2: x < y.
Then max(x,y) = y and min(x,y) = x.
max(x,y) + min(x,y) = y + x = x + y. ✅

In both cases, max(x,y) + min(x,y) = x + y. □

Proof by Contrapositive

💡
Strategy: Proof by Contrapositive
To prove p→q: prove the equivalent ¬q→¬p instead.
Step 1: Assume ¬q (the negation of the conclusion)
Step 2: Use definitions and algebra to derive ¬p
Step 3: Conclude p→q is true.
Prove: If 3n+2 is odd, then n is odd.

Direct attempt fails (knowing 3n+2=2k+1 doesn't directly tell us about n).

Proof by Contrapositive: Prove ¬(n is odd) → ¬(3n+2 is odd), i.e., "n is even → 3n+2 is even."

Assume n is even. Then n=2k for some integer k.
3n+2 = 3(2k)+2 = 6k+2 = 2(3k+1).
Since 3k+1 is an integer, 3n+2 = 2m where m=3k+1. By definition, 3n+2 is even.

Since ¬q→¬p is proven, p→q is proven. □

Prove: If n is an integer and n² is odd, then n is odd.

Contrapositive: Prove "n is even → n² is even."

Assume n is even: n = 2k for some integer k.
n² = (2k)² = 4k² = 2(2k²).
Since 2k² is an integer, n² is even. □

Proof by Contradiction

💡
Strategy: Proof by Contradiction
To prove p: Assume ¬p is true, then derive a contradiction (something that is always false). This forces ¬p to be false, so p must be true.
Prove that √2 is irrational.

Proof: Assume for contradiction that √2 is rational. Then √2 = a/b where a,b∈ℤ, b≠0, and gcd(a,b)=1 (fraction in lowest terms).

Squaring: 2 = a²/b², so 2b² = a².

Thus a² is even → a is even (since if a were odd, a² would be odd). Write a=2c.

Then 2b² = (2c)² = 4c², so b² = 2c².

Thus b² is even → b is even.

But now both a and b are even → 2 divides both → gcd(a,b) ≥ 2. This contradicts gcd(a,b)=1! ⚡

Therefore, our assumption was false. √2 is irrational. □

Show that n³-n is divisible by 6 for all n∈ℕ₀. (CSE 4203 Mid 2023-24)

Method: Factor and case analysis

n³ - n = n(n²-1) = n(n-1)(n+1) = (n-1)·n·(n+1)

This is the product of three consecutive integers.

Divisible by 2: Among any two consecutive integers, one is even. Among (n-1),n,(n+1) we have at least one even. So 2 | (n-1)n(n+1).

Divisible by 3: Among any three consecutive integers, exactly one is divisible by 3. So 3 | (n-1)n(n+1).

Since 2 | n³-n and 3 | n³-n, and gcd(2,3)=1, we have 6 | n³-n. □

Proof of Equivalence

Prove: For integer n, n is odd if and only if n² is odd.

We prove both directions:

Direction 1 (→): If n is odd, then n² is odd.
(Done in direct proof example above: n=2k+1 → n²=2(2k²+2k)+1 is odd.)

Direction 2 (←): If n² is odd, then n is odd.
(Proved by contrapositive: n even → n² even, done above.)

Both directions proven, so "n is odd ↔ n² is odd." □

Formula Reference

All Important Formulas & Facts

⭐ Top 20 Things to Memorize
  • p→q is FALSE only when p=T and q=F
  • p→q ≡ ¬p∨q (conditional as disjunction)
  • Contrapositive ¬q→¬p ≡ p→q (EQUIVALENT)
  • Converse (q→p) and Inverse (¬p→¬q) are NOT equivalent to p→q
  • De Morgan: ¬(p∧q) ≡ ¬p∨¬q; ¬(p∨q) ≡ ¬p∧¬q
  • De Morgan Quantifiers: ¬∀xP(x) ≡ ∃x¬P(x); ¬∃xP(x) ≡ ∀x¬P(x)
  • p↔q ≡ (p→q)∧(q→p) ≡ (p∧q)∨(¬p∧¬q)
  • ¬(p→q) ≡ p∧¬q
  • Precedence: ¬ > ∧ > ∨ > → > ↔
  • Quantifiers (∀,∃) have higher precedence than all connectives
  • ∀x∃y P(x,y) ≠ ∃y∀x P(x,y) (ORDER MATTERS for different quantifiers)
  • Restricted ∀: ∀x<0 P(x) ≡ ∀x(x<0 → P(x))
  • Restricted ∃: ∃x>0 P(x) ≡ ∃x(x>0 ∧ P(x))
  • Modus Ponens: p, p→q ⊢ q
  • Modus Tollens: ¬q, p→q ⊢ ¬p
  • Hypothetical Syllogism: p→q, q→r ⊢ p→r
  • Disjunctive Syllogism: p∨q, ¬p ⊢ q
  • n is even: n=2k; n is odd: n=2k+1
  • Proof by contradiction: assume ¬p, derive r∧¬r
  • p↔q proof: prove p→q AND q→p separately

Critical Pitfalls

❌ Most Common Exam Mistakes
  • Confusing converse with contrapositive: Only contrapositive is equivalent to original!
  • Wrong negation of →: ¬(p→q) ≠ ¬p→¬q. Correct: ¬(p→q) ≡ p∧¬q
  • Wrong quantifier negation: ¬∀xP(x) ≠ ∀x¬P(x). Correct: ≡ ∃x¬P(x)
  • Order of quantifiers: ∃y∀x P ≠ ∀x∃y P — these are different statements!
  • Affirming the conclusion: p→q, q ⊬ p (INVALID fallacy)
  • Denying the hypothesis: p→q, ¬p ⊬ ¬q (INVALID fallacy)
  • De Morgan wrong: Don't forget to BOTH flip the connective AND negate each part
  • "p only if q" confusion: This means p→q, NOT q→p!
  • Domain matters: ∀x(x²≥x) is different over ℝ vs ℤ
  • Circular reasoning (begging the question): Using what you're trying to prove as a step!

• If n≡2: n+1≡0 is divisible by 3

Identify and describe at least five different proof techniques, explain each and when to use it.
Solution

1. Direct Proof: Assume hypothesis p, use axioms/theorems/definitions to derive conclusion q. Use when hypothesis gives direct useful information. E.g.: "n odd → n² odd."

2. Proof by Contrapositive: Prove ¬q→¬p instead of p→q (logically equivalent). Use when ¬q is easier to work with. E.g.: "n² odd → n odd" → easier to show "n even → n² even."

3. Proof by Contradiction: Assume ¬p, derive a contradiction. Use for existence/impossibility proofs. E.g.: "√2 is irrational."

4. Proof by Mathematical Induction: Prove P(1) (base), then P(k)→P(k+1) (inductive step). Use for statements about all positive integers.

5. Proof by Cases: Split into exhaustive cases, prove each. Use when different cases require different reasoning. E.g.: max(x,y)+min(x,y)=x+y (cases x≥y and x<y).

Bonus — Existence Proof: Constructive (find specific example) or non-constructive (prove existence without construction).

Q4(c) — Relation Properties [2×5 marks]
R = {(a,b) | a≡b (mod 7)} on integers. Is R: reflexive, symmetric, antisymmetric, transitive? Partial order?
Solution

Recall: a≡b (mod 7) means 7|(a-b), i.e., a-b=7k for some k∈ℤ.

Reflexive: a≡a (mod 7) since a-a=0=7·0. ✅ YES

Symmetric: If a≡b (mod 7) then 7|(a-b) → 7|(b-a) → b≡a (mod 7). ✅ YES

Antisymmetric: If a≡b and b≡a (mod 7), does a=b? No! e.g., 1≡8 and 8≡1 (mod 7) but 1≠8. ❌ NOT antisymmetric

Transitive: If a≡b and b≡c (mod 7): 7|(a-b) and 7|(b-c) → 7|(a-b+b-c) = 7|(a-c) → a≡c (mod 7). ✅ YES

Partial Order: Requires reflexive + antisymmetric + transitive. Since NOT antisymmetric → NOT a partial order.
It IS an equivalence relation (reflexive + symmetric + transitive).

System Specifications Consistency Check

Are specs consistent: "Whenever system software upgraded, users cannot access filesystem." "If users can access filesystem, can save new files." "If users cannot save new files, system software not being upgraded."

Let: u=upgrading, a=can access, s=can save

Specs: u→¬a, a→s, ¬s→¬u

Note: ¬s→¬u is the contrapositive of u→s — these are consistent.

Set u=T: Then ¬a (can't access). Then a→s: F→s = T (vacuously). ¬s→¬u: can be satisfied with s=F or s=T.

Assignment u=T, a=F, s=F: Check: u→¬a: T→T=T ✅; a→s: F→F=T ✅; ¬s→¬u: T→F=F ❌

Try u=F, a=T, s=T: u→¬a: F→F=T ✅; a→s: T→T=T ✅; ¬s→¬u: F→T=T ✅ All satisfied!

∴ Specs are consistent.

Finding Counterexamples

Show "Every positive integer is the sum of squares of two integers" is false.

Counterexample: 3. Perfect squares ≤ 3 are 0=0² and 1=1². Possible sums: 0+0=0, 0+1=1, 1+1=2, 1+1=2. None equal 3.

∴ 3 cannot be written as sum of squares of two integers → statement is FALSE. □

Satisfiability

Is (p⊕q) ∧ (p↔q) satisfiable?

p⊕q is true when p≠q. p↔q is true when p=q. These two conditions CANNOT both hold simultaneously.

∴ (p⊕q) ∧ (p↔q) is unsatisfiable (contradiction). Note: ¬(p↔q) ≡ p⊕q, so p⊕q ≡ ¬(p↔q), thus (p⊕q)∧(p↔q) ≡ F∧F = contradiction.

Direct Proof — Sum of Two Rationals

Prove: The sum of two rational numbers is rational.

Let r,s be rational. By definition, r=p/q (q≠0) and s=t/u (u≠0) for integers p,q,t,u.

r+s = p/q + t/u = (pu+qt)/(qu)

Since p,q,t,u are integers: pu+qt is an integer, qu is an integer, and qu≠0 (since q≠0, u≠0).

∴ r+s = (pu+qt)/(qu) is rational. □
